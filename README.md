# Shama Challenge Admin Dashboard

Admin dashboard for the Shama Challenge platform.

## Tech stack

- Vite + React + TypeScript
- shadcn/ui + Tailwind CSS
- React Query (TanStack Query v5)
- React Router v6

## Getting started

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The output goes to `dist/`. Served in production via `serve -s dist`.
